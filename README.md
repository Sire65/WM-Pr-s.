# Weihnachtsmarkt-Präsentation – GitHub Pages

Den vollständigen Inhalt dieses Ordners in die Wurzel des GitHub-Repositorys `WM-Pr-sentation` hochladen. `index.html` startet ausschließlich die TV-Präsentation; der Designer ist nicht enthalten.

Aufruf: https://sire65.github.io/WM-Pr-sentation/

Auf dem iPad die Adresse in Safari öffnen, die Präsentation starten, anschließend im Kontrollzentrum „Bildschirmsynchronisierung“ wählen und das Apple TV auswählen. Für Vollbild einmal auf den Bildschirm tippen und „Vollbild“ verwenden.
